# ChIP-seq portal

Open `results/atlas/rnaseq/chipseq.html` through the atlas HTTP server. The
portal is generated by `scripts/atlas/chipseq_portal.py` as part of the normal
atlas build. It loads a separate compact payload, not the RNA expression or
contrast matrices.

## Available evidence

- 465 native consensus support segments, including 335 source-intergenic
  segments, and all 3,080 per-library MACS3 broadPeak calls from PRJNA1090249.
- Study, factor, stage, chromosome, source annotation and visible-interval
  filters; paginated region cards; BED export of the full filtered set.
- Search of current/historical gene IDs and descriptions, or 1-based inclusive
  coordinates. BED/native coordinates stay zero-based and half-open.
- Gene structures loaded by chromosome, strand arrows, pan, zoom, region links,
  links to RNA expression and study design/QC/provenance.

Per-library calls and consensus segments remain distinct and must not be added
together. The consensus consists of intersections, not certified broad domains.
Per-library calls are not newly assigned to genes. Overlapping gene bodies are
display context, separate from native source assignments. No pooled domain
coordinates or continuous tracks are fabricated from peak summaries.

The frozen snapshot adds the two `replicate_evidence.tsv` files from the same
source commit; native sample counts and coordinates are checked at admission.
The chromosome lengths come from retained alignment headers whose FASTA
compatibility was checked by HF; reference identity and source diagnostic
checksum are retained in `config/reference/chipseq_chromosomes_wbps19.json`.

## Continuous signal

The public snapshot omits the real BigWigs. The page explicitly reports that
signal is unavailable until the user opens local files. BigWigs are read in the
browser using the vendored GMOD reader, without uploading them. The file's
chromosome names and lengths must match SM_V10. That checks compatibility, not
the experimental identity or normalization: users select stage, IP/Input and
units from the source. Axes scale independently; missing values are gaps, not
zero signal. Local files are not embedded in shared region links.

Reader: `@gmod/bbi` 11.3.2, bundled as browser ESM using esbuild 0.25.12. Exact
dependencies, license files and the bundle hash are in `vendor/`. To rebuild,
install these pinned packages in an isolated build directory, copy
`chipseq_signal_source.js` into that directory, and bundle it with esbuild
(`bundle: true`, `platform: 'browser'`, `format: 'esm'`, `minify: true`). This
directory should resolve its own `node_modules`; no global package changes are
required. The reader is loaded only when signal files are opened.

## Verification

`tests/test_chipseq_portal.cjs` checks native counts, filtering, BED/UI boundary
conversion, gene lookup, pan/zoom and signal aggregation. The main atlas
validator checks exact per-library and consensus conservation against the frozen
source. `tests/test_chipseq_signal.mjs` exercises the bundled browser reader with
an upstream Volvox parser fixture and rejects mismatched references and malformed
files. The fixture is exclusively test data and never enters the atlas bundle.

Manual browser checks cover the three portal entries, gene/coordinate search,
filters, zoom, region links, responsive layout and scientific information icons.
