# RNA-seq and ChIP-seq integration

This directory is reserved for integrative analyses that consume accepted
HelixForge terminal manifests from RNA-seq and ChIP-seq studies of
*Schistosoma mansoni*.

No integration is authorized until the participating studies, reference and
annotation identities, evidence model, contrasts, and acceptance criteria are
registered. Integration must not depend on upstream Nextflow work directories
or cache entries.
