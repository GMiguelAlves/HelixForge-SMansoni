# PRJNA704646

## Decisão científica

base genética da resposta ao praziquantel. Fonte primária: https://doi.org/10.1126/scitranslmed.abj9114.

Foram selecionados **24 runs RNA-seq** de *Schistosoma mansoni*, organizados em **8 amostras biológicas**. Layout: `PAIRED`. Modo HelixForge: `import`.

## Limitação congelada

As três bibliotecas de cada combinação foram produzidas do mesmo pool de RNA. Elas são réplicas técnicas e serão consolidadas; depois da consolidação resta n=1 biológico por combinação, portanto DE inferencial fica bloqueada.

Os FASTQs brutos não são versionados. `runs.tsv` fixa URLs, MD5, tamanhos e a relação run → amostra; o snapshot ENA imutável está em `provenance/PRJNA704646/source_snapshots/ena_read_run.tsv`.
