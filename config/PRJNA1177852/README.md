# PRJNA1177852

## Scientific decision

Meclonazepam time course. Primary source:
https://doi.org/10.1371/journal.pntd.0012969.

The input package selected **8 RNA-seq runs** from *Schistosoma mansoni*,
representing **8 biological samples**. Layout: `PAIRED`. HelixForge mode:
`import`.

## Frozen limitation

There is one library per time point and no parallel control series. The
deposit is quantified as a descriptive time course linked to the publication,
without standalone inferential differential expression.

Raw FASTQs are not versioned. `runs.tsv` freezes URLs, MD5 checksums, sizes,
and run-to-sample relationships. The immutable ENA snapshot is
`provenance/PRJNA1177852/source_snapshots/ena_read_run.tsv`.
