## Limitação congelada

Os FASTQs brutos não são versionados. `runs.tsv` fixa URLs, MD5, tamanhos e a relação run → amostra; o snapshot ENA imutável está em `provenance/PRJNA494090/source_snapshots/ena_read_run.tsv`.
